That settles the core behavior. We now have the following agreed specification.
Preserve what works
- Support beginners and intermediates, with equal attention to strength and hypertrophy.
- Repeat productive training without requiring novelty.
- Start with four-week blocks. Change length only with sufficiently confident, current companion feedback based on individual history.
- Keep training days and maximum session duration fixed; suggest changes separately.
Use performance to guide adjustments
- Collect RIR/RPE from at least the last working set.
- Compare exposures only when load, sets, rep range, and target effort are comparable.
- Distinguish flat performance from deterioration. Flat performance can justify a small next-block adjustment; it does not establish that hypertrophy has stopped.
- Two consecutive comparable misses establish deterioration. A miss means falling below the minimum rep range or below the previous exposure’s total reps.
- Several deteriorating exercises trigger a program deload: at least two designated main movements for strength; several exercises for hypertrophy.
Individualize prescriptions
- Use companion-calibrated curves to estimate loads for 1–10 reps at 0–4 RIR, allowing higher RIR for recovery sessions.
- Between imports, update estimated strength from recent mobile performance while retaining the personalized curve shape.
- Keep prediction and model-learning eligibility separate: easier recovery sets need not update strength estimates.
- Let Fury, Precision, and “I want to get out of here” steer next-block adjustments, including main lifts.
- Support separate liked, disliked, and anchored exercise preferences.
Respond to stalls and fatigue
- Prefer load reset → rep-range change → exercise variation → set-count adjustment, with history and mood influencing the choice.
- Apply ordinary stall adjustments between blocks; retain 10% as the initial load-reset default when that response is selected.
- A fatigue deload lasts one normal week’s worth of sessions, keeping exercises, sets, and rep ranges while prescribing two additional RIR, minimum four, with progression suspended.
- Start the next block one RIR easier than the previous normal prescription, then rebuild.
Respond to pain
- A 7–10 pain report immediately ends the affected exercise’s remaining sets.
- First return exposure starts at the proposed 50% e1RM load.
- Persistent discomfort ends the remaining sets and triggers substitution next exposure; otherwise, allow gradual rebuilding.
- Prompt for discomfort during that first return session only. Manual pain reporting remains available afterward.

These are agreed product requirements; no implementation changes have been made.
