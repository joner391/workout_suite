# Specification: Individualized 1RM & Endurance Filter

## 1. System Overview

Track individual strength ($1\text{RM}$) and movement-specific repetition endurance ($k$) per exercise using an adaptive Linear Kalman Filter (KF). The system operates on the linearized Lombardi power-law model:

$$w = 1\text{RM} \cdot r_{\text{eff}}^{-k} \iff \ln(w) = \ln(1\text{RM}) - k \cdot \ln(r_{\text{eff}})$$

---

## 2. Ingestion & Pre-Processing Rules

Run this filter per exercise stream (e.g., Squat, Bench Press, Conventional Deadlift stored independently).

1. **Intra-Session Filtering:**
* Only accept the **top 2 sets with the lowest RIR** per exercise per session.
* If $>2$ sets share the lowest RIR, select the 2 sets with the highest loads.
* Discard any set where $\text{RIR} > 3$ (unreliable subjective signal).


2. **Effective Repetitions:**

$$r_{\text{eff}} = \text{reps} + \text{RIR} \quad \text{or} \quad r_{\text{eff}} = \text{reps} + \max(0, 10 - \text{RPE})$$


* Enforce lower bound: $r_{\text{eff}} \ge 1.0$.



---

## 3. State-Space Formulation

### State Vector

$$\mathbf{x}_t = \begin{bmatrix} x_0 \\ x_1 \end{bmatrix} = \begin{bmatrix} \ln(1\text{RM}_t) \\ k_t \end{bmatrix}$$

### Observation

$$z_t = \ln(w_t)$$

$$\mathbf{H}_t = \begin{bmatrix} 1 & -\ln(r_{\text{eff}, t}) \end{bmatrix}$$

### Noise Models

* **Measurement Noise ($R_t$):** Scales non-linearly with rep count to discount high-rep variance:

$$R_t = \sigma_{\text{base}}^2 \cdot \left(1 + \lambda \cdot r_{\text{eff}, t}^2\right)$$


* **Process Noise ($\mathbf{Q}$):** Allows strength to adapt while constraining the biological endurance parameter $k$:

$$\mathbf{Q} = \begin{bmatrix} q_{\ln 1\text{RM}} & 0 \\ 0 & q_k \end{bmatrix}$$



---

## 4. Hyperparameters & Priors

### Baseline Constants

* $\sigma_{\text{base}} = 0.025$ ($\approx 2.5\%$ measurement noise)
* $\lambda = 0.015$ (variance amplification factor for high reps)
* $q_{\ln 1\text{RM}} = 1.0 \times 10^{-4}$ (strength drifts over time)
* $q_k = 1.0 \times 10^{-6}$ (endurance slope is relatively stationary)

### Exercise-Specific Initial Priors ($\mathbf{x}_0$, $\mathbf{P}_0$)

| Exercise | Initial $1\text{RM}_0$ | Initial $k_0$ | Initial Covariance $\mathbf{P}_0$ |
| --- | --- | --- | --- |
| **Bench Press** | User entry or 1st set load | $0.085$ | $\text{diag}(0.04,\, 0.002)$ |
| **Back Squat** | User entry or 1st set load | $0.095$ | $\text{diag}(0.04,\, 0.002)$ |
| **Deadlift** | User entry or 1st set load | $0.075$ | $\text{diag}(0.04,\, 0.002)$ |

---

## 5. Discrete Kalman Filter Update Algorithm

For each accepted set $(w_t, r_{\text{eff}, t})$:

```python
import numpy as np

def update_1rm_filter(x, P, weight, r_eff, Q, base_sigma=0.025, lam=0.015):
    # 1. Time Update (Predict)
    # State transition matrix A = I
    x_pred = x.copy()
    P_pred = P + Q

    # 2. Measurement Vector and Noise
    z = np.log(weight)
    H = np.array([[1.0, -np.log(r_eff)]])
    R = (base_sigma ** 2) * (1.0 + lam * (r_eff ** 2))

    # 3. Measurement Update (Correct)
    y = z - (H @ x_pred)[0]                         # Innovation (scalar)
    S = (H @ P_pred @ H.T)[0, 0] + R               # Innovation covariance
    K = (P_pred @ H.T) / S                         # Kalman gain (2x1)

    x_new = x_pred + K.flatten() * y
    P_new = (np.eye(2) - K @ H) @ P_pred

    # Constrain k to plausible human boundaries [0.03, 0.16]
    # NOTE: Box-clipping k in [0.03, 0.16] is an operational heuristic override for numerical 
    # stability, preventing filter divergence or unphysiological slopes under noisy/sporadic logs.
    x_new[1] = np.clip(x_new[1], 0.03, 0.16)

    return x_new, P_new

# Recover Human-Readable Outputs

# k = x[1]
# e1RM_std_err = e1RM * np.sqrt(P[0, 0])

```

## 6. Edge Cases, Invariant Rules & Lift-Specific Calibration

* **True 1RM Test ($r_{\text{eff}} = 1.0$):** $\mathbf{H} = [1, 0]$. Mathematically bypasses $k$ updates and updates only $1\text{RM}$.
* **Failed Sets ($0$ completed reps):** Do not feed into the filter.
* **Warm-up Sets ($\text{RIR} > 3$):** Discard entirely during ingestion.
* **Deadlift Compensatory Scalar Boundary:**
  - The $+10\%$ deadlift compensatory multiplier ($\times 1.10$) documented in empirical literature applies **exclusively** to static linear heuristic formulas (e.g., Epley / Brzycki) during **Tier 1 in-app estimation**.
  - In this **Tier 2 Kalman Filter**, deadlift fatigue kinetics (absence of stretch-shortening cycle, static inertia, grip/erector bottlenecks) are modeled **natively** through the dynamic state variable $k_t$ initialized with a conservative prior $k_0 = 0.075$. Therefore, **no $+10\%$ heuristic scalar should ever be applied** to the Kalman filter state estimates or calibrated parameters.
* **Box-Clipping Stability Override:**
  - The hard bounding of $k_t \in [0.03, 0.16]$ prevents unphysiological parameter drift during prolonged periods of sub-maximal testing or high-RPE cluster sets. Extreme values outside this corridor indicate either pacing artifacts or non-standard rest intervals rather than true biological repetition endurance.
